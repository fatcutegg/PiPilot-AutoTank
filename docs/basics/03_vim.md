# ⌨️ Vim 入門：ターミナルでコードを編集しよう

**Vim** はターミナル（黒い画面）の中で使えるテキストエディタです。
Raspberry Piにはマウスやディスプレイがないことも多いので、Vimを使いこなすと作業がラクになります！

---

## 🤔 なぜVimを使うの？

Raspberry Piにリモート接続（SSH）すると、グラフィカルなエディタは使えません。
ターミナルだけで操作できる **Vim** が大活躍します。

---

## 🚦 Vimの2つのモード

Vimには「モード」という概念があります。これが最初の難関です！

| モード | 役割 | 切り替え方 |
|--------|------|-----------|
| **ノーマルモード** | カーソル移動・コマンド実行 | `Esc` キー |
| **インサートモード** | 文字を入力する | `i` キー |

> 起動直後は**ノーマルモード**です。`i` を押すと文字が入力できます。

---

## 🚀 基本的な使い方

### ファイルを開く

```bash
vim main.py
```

---

### 文字を入力する

1. `i` キーを押す（インサートモードに入る）
2. 文字を入力する
3. `Esc` キーを押す（ノーマルモードに戻る）

---

### 保存して閉じる

ノーマルモードで以下を入力：

```
:wq   ← 保存して終了（write & quit）
:q!   ← 保存せずに強制終了
:w    ← 保存だけする（終了しない）
```

---

## 📋 よく使うコマンド一覧

| コマンド | 意味 |
|----------|------|
| `i` | インサートモードに入る |
| `Esc` | ノーマルモードに戻る |
| `h` `j` `k` `l` | 左・下・上・右にカーソル移動 |
| `dd` | 1行削除 |
| `yy` | 1行コピー |
| `p` | 貼り付け |
| `u` | 元に戻す（Undo） |
| `/検索ワード` | ファイル内を検索する |
| `:wq` | 保存して終了 |
| `:q!` | 保存せず強制終了 |

---

## 💡 困ったときは

Vimが思い通りにならないときは、まず **`Esc` を数回押して** ノーマルモードに戻ろう！

---

## 🎯 ミッション

1. ターミナルで `vim test.txt` を実行してVimを開こう
2. `i` を押して「Hello, Vim!」と入力しよう
3. `Esc` → `:wq` で保存して終了しよう
4. `cat test.txt` で内容を確認しよう
