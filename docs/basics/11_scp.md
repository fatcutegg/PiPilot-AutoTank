# ✈️ 基礎知識 11：ファイルを送受信しよう（SCP コマンド入門）

戦車を走らせて集めたカメラ映像や操作データは、最終的にみんなのデータをひとつにまとめて AI（モデル）を学習させるために、データ送信用の「共有の Raspberry Pi（またはサーバー）」に送る必要があります。

ネットワーク経由で安全にファイルやフォルダをコピーできる便利なコマンド **`scp`（セキュアコピー）** について学びましょう！

---

## 📂 SCP コマンドってなに？

`scp`（Secure Copy Protocol）は、SSH の仕組みを利用して、**ネットワークで繋がった別のコンピュータ同士でファイルを安全に送受信する**ためのコマンドです。
スマホの AirDrop や、ファイルの共有フォルダのような役割を、ターミナルからコマンドを入力するだけで実行できます。

---

## 🚀 基本的な使い方

SCP の基本形はとてもシンプルで、ファイルをコピーする `cp` コマンドと似ています：

```bash
scp [送りたいファイル] [送り先のユーザー名]@[IPアドレス]:[保存するフォルダの場所]
```

### 1. 1つのファイルを別のPCに送る
例えば、自分のパソコンにある `test.txt` を、IPアドレスが `192.168.1.100` の Raspberry Pi（ユーザー名: `pi`）のホームフォルダ（`~/`）に送りたい場合：

```bash
scp test.txt pi@192.168.1.100:~/
```

### 2. フォルダ丸ごと送る（データセットを送るとき）
画像やデータがたくさん入った「フォルダ（ディレクトリ）」を丸ごと送るには、**`-r`** というオプション（フォルダ内の子ファイルを再帰的にすべて送る指示）を付けます。

```bash
# 「dataset」フォルダを丸ごと送信する
scp -r dataset/ pi@192.168.1.100:~/Projects/
```

### 3. SSH Config（設定ファイル）を使ったカンタン送信
すでに `~/.ssh/config` に接続先（例えば `Host share-pi`）を設定している場合は、IPアドレスやユーザー名の代わりにその名前を使うことができて、とってもスマートです！

```bash
# 共有Piにフォルダを送信する
scp -r dataset/ share-pi:~/shared_dataset/
```

---

## 👤 共有Piへデータを提出する手順

今回のプロジェクトでは、みんなが手動運転で集めたデータセット（`dataset/` フォルダ）を、先生が用意した「データ回収用の Raspberry Pi（`share-pi`）」に送信して合体させます。

自分のパソコンのターミナルで、プロジェクトフォルダ（`PiPilot-AutoTank`）にいることを確認して、以下のコマンドを実行しましょう！

```bash
# 送信コマンドの例（提出先の設定や名前は、先生の指示に合わせて変更してね）
scp -r dataset/ share-pi:~/PiPilot-AutoTank/received_data/yourname_dataset/
```

> **⚠️ 注意（中学生向け）：**
> - 送り先のフォルダの最後に `yourname_dataset` のように自分の名前をつけておくと、他の人のデータと混ざらずに綺麗に合体させることができます。
> - データ量が大きい（画像が数千枚ある）と、送信に数分かかることがあります。進捗のパーセント（%）が 100% になるまでターミナルを閉じずに待ちましょう！

---

**💡 まとめ：**
`scp` コマンドを使えば、ケーブルを繋ぎ替えたり USB メモリを使ったりしなくても、コマンド一つで別のコンピュータにファイルを届けることができます。これでデータの提出準備もバッチリですね！
