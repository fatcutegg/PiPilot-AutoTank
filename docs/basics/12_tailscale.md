# 🌐 基礎知識 12：Tailscale を使ってどこからでも戦車に接続しよう！

学校の実験室や外出先にある「ポケットWi-Fi（Pocket Wi-Fi）」などを使っているとき、PCと戦車（Raspberry Pi）を同じWi-Fiに繋いでいるはずなのに、なぜかSSH接続できないことがあります。

これは、ルーターの安全機能（プライバシーセパレータやAP隔離など）によって、**同じWi-Fiに繋がっている機器同士の直接の通信がブロックされている**のが原因です。

そんなときの救世主が**「Tailscale（テイルスケール）」**です！
これを使うと、インターネット経由でPCと戦車を安全な「仮想の専用線」で繋ぎ、直接通信できないネットワーク環境でも問題なくSSH接続できるようになります。

---

## 🔑 Tailscale ってなに？

Tailscaleは、世界中どこにあるコンピュータ同士でも、まるで同じ部屋の同じネットワークにいるかのように繋ぐことができる**「VPN（仮想専用線）」**のサービスです。

*   **設定が超カンタン**：難しいルーターの設定（ポート開放など）は一切不要。
*   **安全・セキュア**：通信は暗号化されるため、他の人にのぞき見られる心配はありません。
*   **個人利用は無料**：アカウントを作れば、誰でも無料で使うことができます。

---

## 🛠️ セットアップの 3 ステップ

設定は「アカウント作成」「PC側の準備」「戦車（ラズパイ）側の準備」の3ステップです。

### STEP 1：Tailscale アカウントを作ろう

まずは、ログインに必要なアカウントを作成します。

1.  ブラウザで [Tailscale 公式サイト](https://tailscale.com/) にアクセスします。
2.  右上にある **「Get Started」** または **「Use Tailscale for free」** をクリックします。
3.  Google アカウントや GitHub アカウントなどを使ってログインし、サインアップ（会員登録）を完了させます。

---

### STEP 2：パソコンに Tailscale をインストールしよう

あなたのパソコンに Tailscale のアプリを入れて接続します。

1.  [Tailscale ダウンロードページ](https://tailscale.com/download) から、お使いのOS（Windows / macOS / Chromebook など）に合ったアプリをダウンロードしてインストールします。
2.  インストール後、アプリを起動して **「Log in」** をクリックします。
3.  ブラウザが開くので、STEP 1 で作ったアカウントでログインして認証を完了させます。
4.  パソコンが Tailscale のネットワーク（VPN）に参加し、準備完了です！

---

### STEP 3：戦車（Raspberry Pi）に Tailscale をインストールしよう

戦車にも Tailscale を入れて、パソコンと繋がるようにします。
（※この作業中は、一時的に戦車をディスプレイやキーボードに繋いで操作するか、ローカル通信ができる環境でSSH接続して操作してください）

1.  戦車のターミナル（黒い画面）を開き、以下のインストールコマンドを実行します：
    ```bash
    curl -fsSL https://tailscale.com/install.sh | sh
    ```
2.  インストールが終わったら、Tailscale を起動してログイン用URLを取得します：
    ```bash
    sudo tailscale up
    ```
3.  画面に以下のような英語のメッセージと、ログイン用URLが表示されます：
    ```text
    To authenticate, visit:
    https://login.tailscale.com/a/xxxxxxxxx
    ```
4.  表示されたURL（`https://...`）を**パソコンのブラウザにコピー＆ペースト**して開きます。
5.  STEP 1 と同じアカウントでログインし、**「Connect」** をクリックして認証します。
6.  戦車のターミナル画面で認証成功のメッセージが出れば完了です！

---

## 🚀 Tailscale を使って SSH 接続してみよう

セットアップが終わると、PCと戦車にそれぞれ「Tailscale専用のIPアドレス（`100.XX.XX.XX` のような数字）」が割り当てられます。

1.  パソコンで [Tailscale 管理画面（Admin Console）](https://login.tailscale.com/admin/machines) を開くか、PCの Tailscale アプリのメニューを開きます。
2.  登録されているデバイス一覧から、戦車（Raspberry Pi）のIPアドレス（例：`100.115.80.42`）をコピーします。
3.  パソコンのターミナルを開き、このIPアドレスを使ってSSH接続のテストをします：
    ```bash
    ssh pi@100.XX.XX.XX
    ```
    （※`pi` の部分は戦車のユーザー名、`100.XX.XX.XX` はコピーしたIPアドレスに変えてください）
4.  これで無事に接続できれば大成功です！🎉

### 💡 さらに便利にする設定（Config の書き換え）

毎回長いIPアドレスを入力しなくても **`ssh tank`** だけで繋がるように、パソコンの `~/.ssh/config` を書き換えておきましょう。

パソコン側の設定ファイル（`~/.ssh/config`）をエディタで開き、`HostName` の部分を Tailscale のIPアドレスに変更します：

```text
Host tank
    HostName 100.XX.XX.XX  # ここを Tailscale のIPアドレスに変更する！
    User pi
    IdentityFile ~/.ssh/tank_key
```

これで、学校の実験室のポケットWi-Fi環境であっても、家であっても、インターネットさえ繋がっていればいつでもどこからでも `ssh tank` で戦車を操作できるようになります！

---

**💡 まとめ：**
ルーターの制限やローカル環境のせいで通信できないときは、Tailscale を使うことで安全かつ手軽にネットワーク問題を突破できます。これでロボット開発がさらに快適になりましたね！
