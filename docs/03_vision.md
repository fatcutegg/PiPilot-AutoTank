# 🧠 第3章：タンクに「視力」をあたえよう (AIビジョン篇)

いよいよAIの登場です。この章では、タンクが自分の「目（カメラ）」を使って、道をどうやって認識しているのかを実験します。

## 1. AIの視力テスト開始
ターミナルで次のコマンドを実行して、AIプログラムを起動しましょう：

```bash
python tests/verify_vision.py
```

## 2. AIはどうやって考えているの？
AIが風景を見てから行動を決めるまでには、**4つのステップ**があります。

1. **📸 カシャッ！写真を撮る**
   タンクのカメラが、ものすごいスピードで前方の写真を撮ります。処理を速くするために、写真のサイズは小さめ（160x120）に設定されています。
2. **✂️ 写真を整える（前処理）**
   AIの脳は普通の写真をそのまま理解できません。だから、プログラム（`cv2`）を使って写真をAIが読みやすい「数字のデータ（行列）」に変換します。
3. **🤔 AIの推論（考える）**
   数字になったデータを、あらかじめ学習しておいたAIモデルに渡します。するとAIは「これは左折だ！」「いや、直進の確率が高い！」と計算します。
4. **✅ 答えを出す**
   AIが一番確率が高いと判断した行動（例：`LEFT` や `FORWARD`）を画面に表示します。

## 🎯 キミへのミッション：
1. 「左折」や「右折」の標識をカメラの前に置いて、画面に正しく `LEFT` や `RIGHT` と表示されるか確認しよう！
2. 標識を近づけたり遠ざけたり、部屋を暗くしてみたりすると、AIの判断はどう変わるかな？
3. **もしAIが間違えたら…？** どうして間違えたのか理由を考えてみよう（例：影のせいかな？もっと色々な角度から学習させる必要があるかな？）。
