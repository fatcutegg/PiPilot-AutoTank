# 🎮 第2章：キミがドライバーだ！(手動コントロール篇)

タンクに「自動運転」を教える前に、まずは**キミ自身が素晴らしいドライバーになる**必要があります！キミの運転データが、将来AIの「教科書」になるからです。

## 1. エンジンスタート！
パソコンの黒い画面（ターミナル）で、次の呪文（コード）を入力して実行します：

```bash
python src/teleop_keyboard.py
```

これで準備完了！キーボードの `↑` `↓` `←` `→` キーを使って、タンクを自由に操縦できます。終わる時は `q` キーを押してね。

## 2. スムーズな走りの秘密（魔法のコード）

タンクを動かしてみると、急発進せずにス～ッと滑らかに走り出すことに気づきましたか？
実は、プログラムの中に**2つの魔法**が隠されています。

### ✨ 魔法1：PWM スムーズ加速 (Ramping)
自転車をこぎ始める時、いきなりトップスピードにはならないよね？
プログラムの中で `self.ramp_step = 5` と設定することで、モーターのパワーを階段のように少しずつ上げるようにしています。これでタンクが「ガクッ」と急発進するのを防いでいるのです。

### 💪 魔法2：デッドゾーン（死角）の突破
重い箱を押す時、弱い力だと箱はピクリとも動きません。モーターも同じで、少しの電気では回転を始められません。
そこで、止まっている状態から動く時は、**「最低でもこれくらいの力でスタートする（`self.min_power = 40`）」**という設定をしています。自転車の最初のペダルを「グッ！」と強く踏み込むのと同じですね！
