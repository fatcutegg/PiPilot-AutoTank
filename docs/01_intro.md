# 🌟 第1章：スマートタンクを知ろう！

自動運転タンクには、人間と同じようにいくつかの重要な「パーツ」が備わっています。まずは、この小さな車の秘密を見てみましょう。

## 🧠 大脳：Raspberry Pi（ラズベリーパイ）
タンクの背中に乗っている小さな緑色の基板。これは、クレジットカードサイズの**超小型パソコン**です。
タンクが「どう動くか」を考え、命令を出す一番大切なパーツです。

## 👁️ 目：カメラモジュール
タンクの前面についているカメラは、人間の「目」の役割を果たします。
前方の道路や、右折・左折の標識を見つけて、その映像を「大脳」に送ります。

## 💪 筋肉：モーターとタイヤ
「大脳」から電気の信号（命令）を受け取ると、モーターが回転してタイヤを動かします。これでタンクは前進したり、カーブを曲がったりできるのです！
