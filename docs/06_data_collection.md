# 📹 第6章：キーボード操縦でデータを集めよう

自動運転 AI を育てるための「教科書」となる操縦データを自分で集めましょう。
あなたがキーボードで戦車を走らせると、カメラの映像と、その瞬間にあなたが「どのキー（前進・右折など）を押したか」がペアで保存されます。

---

## 1. データ収集プログラムの起動
戦車側（`ssh tank`）で以下を実行します：

```bash
# プロジェクトフォルダへ移動
cd ~/Projects/PiPilot-AutoTank

# 仮想環境を有効化していることを確認して実行
conda activate tank_py39  # または source ~/venv_tank/bin/activate
python src/data_logger.py
```

---

## 2. 操作方法
プログラムが起動すると、キーボード入力を待ち受けます：
*   **`r` キー**：データの記録を開始 / 一時停止します。（録画が始まるとカメラ映像が保存されます）
*   **方向キー（↑ ↓ ← →）**：戦車を操縦します。
*   **`q` キー**：プログラムを安全に保存して終了します。

---

## 💡 うまくデータを集めるコツ

*   **滑らかに走らせよう**：コースの黒い線に沿って、ガクガクさせずに滑らかに走らせるのが基本です。
*   **リカバリーデータを含めよう**：わざと少しコースアウトした状態から復帰するような運転データを含めると、AIが「コースアウトしそうになったときの正しい戻り方」を学べるため、より賢いAIになります。
*   **目標枚数**：画像が **3000〜5000枚** ほど集まるまで走りましょう！
